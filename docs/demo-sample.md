## Binary search

Binary search finds a target in a sorted list by checking the middle item and discarding the half that cannot contain the target. It repeats this process until it finds the target or the remaining range is empty. Each step roughly halves the search range, so the number of checks grows logarithmically with the list size.

Binary search requires sorted data. It is not a safe choice when the list order is unknown or changes during the search.
